## 🚀 Key Features

- **Luxury Design & Aesthetics:** High-end typography (Cinzel, Outfit, Playfair Display), custom ambient glow effects, responsive luxury cards, and micro-animations.
- **Automated Lead Management:**
  - Automated lead capture via interactive inquiry forms.
  - Integration with **Google Sheets** for real-time CRM storage.
  - Instant **Email Notifications** for sales reps and inquiries.
  - Automated **WhatsApp Nurturing** workflows.
- **Interactive UI/UX:**
  - Dynamic Hero slideshow.
  - Interactive Project Entrance Arches & Gallery.
  - Instant layout plan download system.
  - Filterable property amenities & project locator.
- **Mobile Responsive:** Seamless experience across smartphones, tablets, and desktop displays.

## 🛠️ Tech Stack

- **Frontend:** Semantic HTML5, Vanilla CSS3 (Custom design system & animations), Vanilla Modern JavaScript (ES6+)

- **Backend & Integrations:**
  - Google Apps Script (Web App webhook API)

## 💻 Local Development Setup

To preview and run the website locally:

```powershell
# Clone the repository
git clone https://github.com/arishkhan0405/HnatasProperties.git

# Navigate to project directory
cd HnatasProperties

# Start the local development server
powershell -ExecutionPolicy Bypass -File .\serve.ps1
# or run the batch launcher
.\start-server.bat
```

Open your browser and navigate to:
```
http://localhost:8080
```
